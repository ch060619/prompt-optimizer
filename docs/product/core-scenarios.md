## 状态与边界

状态：`defined-not-e2e-validated`。本文件定义首发 Windows/Linux 的核心用户旅程，不声明 Rabbit Code Agent、GUI、Provider 或本地模型功能已经实现。机器登记见 `docs/product/core-scenarios.yml`，结构校验由 `scripts/check_core_scenarios.py` 执行。

所有场景默认使用 Provider Mock、Loopback 或 `OfflineRuleProvider`；真实 API Key、付费额度、真实本地模型安装和未固定的平台设备不属于本轮证据。每张测试卡都必须在实现对应 RC 后重新执行，记录环境、版本、输入摘要、结果和证据路径。

## 统一失败语义

- **拒绝**：权限或边界拒绝必须产生可见事件，不能转成成功或静默跳过。
- **失败**：保留原始输入、已提交检查点和结构化错误；用户可以修复后重试。
- **取消**：向下传播到模型、工具和子进程；取消后不能继续产生新事件。
- **降级**：明确显示 local/cloud/fallback、原因和数据边界；不得把离线规则冒充模型。
- **恢复**：只自动重放幂等且已确认安全的动作；不确定的写操作必须人工确认。
