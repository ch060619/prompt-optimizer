# RC-041 版本范围与稳定版边界

RC IDs: RC-041

## 决策

MVP 是首个稳定版前的纵向最小闭环，用于尽早验证工作区、Agent、权限、工具、CLI/无头、最小 GUI、提示词优化和离线规则是否能通过同一核心服务协作。MVP 不是把 R2 或 R4 永久降级为后续功能的理由。

首个稳定版覆盖当前计划的 `RC-001..RC-310`，并把 R1 至 R6 和原初 12 类计划全部列为稳定版门槛。当前登记冻结范围和依赖，不声称这些项目已经实现或已经通过发布验收。

## 版本分层

| 版本 | 进入内容 | 出口标准 |
| --- | --- | --- |
| MVP | 工作区发现、上下文、Agent 循环、权限、工具、终端、诊断、星星优化和离线规则的最小纵向路径；CLI/无头与最小 GUI 使用同一核心 | 请求、取消、恢复、拒绝和离线降级可观察，默认使用 Mock/离线规则，不伪造真实服务结果 |
| 首个稳定版 | `RC-001..RC-310`、R1-R6、原初 12 类计划和 Windows/Linux 首发发布门槛 | 需求、实现、测试、文档和发布证据闭环；没有仅文档完成的功能项或无限期后续项 |
| 后续增强版 | 当前稳定版之外的新范围，例如 macOS/Apple GPU、更多 ARM/Linux 环境和签名/商店渠道 | 每项增强都有独立 RC、理由、负责人、固定验证环境和进入条件，不改变首个稳定版承诺 |

## R1-R6 稳定版门槛

| 要求 | 首个稳定版必须交付 | 主要风险/依赖 |
| --- | --- | --- |
| R1 | 固定公开来源、clean-room 记录、CLI 行为测试和 GUI 功能矩阵 | W0/W1 来源与合规门禁，W3/W6/W7/W9 行为实现 |
| R2 | 每个独立 GUI 页面有批准的兔兔素材或派生品牌元素，并通过视觉回归、布局和无障碍验收 | 素材授权、GUI 路由、视觉回归和人工验收 |
| R3 | 星星优化覆盖用户 API、Loopback FastAPI 和离线规则；保留原文并通过 revision、取消、降级和 E2E 验证 | Provider、本地运行器、GUI/CLI 入口和整合测试 |
| R4 | API/无 API 双入口、Gemma/Qwen 安装验证、切换/修复/卸载和统一工作区入口 | Provider、密钥边界、本地模型生命周期和首发平台 |
| R5 | `RC-001..RC-310` 全部进入稳定版路线，并能追踪到实现、测试、文档或发布证据 | 追踪门禁；不接受只有页面或文档而没有实现/测试的完成声明 |
| R6 | OpenAI、Gemini、Claude/Anthropic 原生协议的免费契约/Mock 测试；真实连接仅在用户提供 Key 后手动执行 | 协议适配、错误分类、密钥保管和用户自有资源 |

## 依赖波次

首个稳定版沿用执行计划的 W0-W12 依赖关系。所有波次属于稳定版路线；“进入路线”不等同于“当前已完成”。

| 波次 | 稳定版职责 | 进入依据 |
| --- | --- | --- |
| W0-W1 | 基线恢复、合法性、产品范围和来源冻结 | 当前仓库可读；M0 证据无阻塞 |
| W2-W3 | 共享协议、数据模型、Agent Core、工具和权限纵向闭环 | W1 通过 |
| W4-W5 | Provider、密钥、本地运行器和 Gemma/Qwen 生命周期 | W3 协议稳定 |
| W6-W8 | CLI/TUI、GUI、视觉系统和星星优化 | Core、Provider、本地路径和视觉边界稳定 |
| W9-W10 | 跨端旅程、安全、性能、故障恢复和发布阻断 | W6-W8 通过 |
| W11-W12 | 文档、未签名制品、SBOM、Release 和最终验收 | W10 通过 |

## 延后项

延期只表示稳定版之外的新范围，不表示 R1-R6 或当前 310 项计划被搁置。每个延期项都有复审触发条件和可验证进入条件。

| 项目 | 当前处理 | 理由 | 进入条件 |
| --- | --- | --- | --- |
| macOS/Apple GPU | 稳定版之外 | 首发边界是 Windows/Linux，避免无验证环境的发布承诺 | 新 RC、固定设备/CI、许可证和安装/权限/发布验收 |
| ARM64/额外 Linux | 稳定版之外的尽力扩展 | 构建成功不等于兼容性；需要固定 runner 和真实生命周期测试 | 固定 runner、驱动/运行器/模型记录、CLI/制品/模型测试 |
| 签名制品/商店渠道 | 稳定版之外 | 当前采用零付费、未签名制品和 SHA-256，不依赖账户或证书 | 明确授权的证书/账户/密钥流程、签名验证和平台审核测试 |

## 完成边界

机器可读登记见 [`release-scope.yml`](release-scope.yml)，校验器见 [`check_release_scope.py`](../../scripts/check_release_scope.py)。校验器拒绝缺失的 R1-R6、12 类计划、RC-001..RC-310、理由或进入条件，也拒绝 `indefinite`、`永久后续` 和 `无限期` 等无限期措辞。

本 RC 记录的是版本范围决策；真实 Provider、真实本地模型、跨平台实机、视觉回归和发布验收仍必须由对应实现/测试 RC 提供证据。
