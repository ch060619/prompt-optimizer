# Rabbit 源图交付与导出门禁

- RC ID: RC-127
- 状态：源图、桌面/终端派生物、应用图标和 Rabbit Code 发布授权已交付
- 前置条件：技术源图与用户发布授权已登记

## 目标与边界

本文件把 RC-123 的派生变体规范落实为可执行的交付门禁，覆盖留白、裁切焦点、清晰度、PNG/WebP 文件预算、应用图标预算和母版保护。用户提供的 `兔兔素材.png` 是登记母版；桌面和终端扣图分别以固定哈希保存在项目根目录并发布到 `frontend/public/`。用户已允许 Rabbit Code 项目发布；通用商业许可不在该授权范围内。

## 文件层级与母版保护

| 层级 | 位置/标识 | 写入规则 |
| --- | --- | --- |
| 外部源图 | 用户在本轮对话中提供的素材 | 仅用于一次性登记，不作为运行时依赖 |
| 无损母版 | `兔兔素材.png` | 只读；禁止构建脚本、裁切脚本和格式化工具覆盖 |
| 派生发布物 | `frontend/public/` 下按 manifest 命名的 PNG/WebP/图标 | 只能由已登记母版生成；每个文件记录源哈希、尺寸、主题和导出时间 |
| 构建输出 | `frontend/dist/` | 可删除、可重新生成；不得反向作为源图或母版 |

导出过程必须在临时目录完成，最后一步才将通过检查的派生文件写入发布目录。任何失败都必须保留母版和现有发布物不变；运行时不得依赖桌面外部路径。

## 文件预算

预算是单文件上限，按二进制文件实际字节数检查；未达到预算不能替代清晰度、色彩和最小尺寸检查。

| 变体 | PNG 1x / 2x | WebP 1x / 2x | 说明 |
| --- | ---: | ---: | --- |
| `full` | 400 KiB / 900 KiB | 220 KiB / 500 KiB | 首页和 onboarding；保留完整主体和安全区 |
| `empty` | 180 KiB / 420 KiB | 100 KiB / 240 KiB | 空状态插图；透明边缘不能出现光晕 |
| `avatar` | 64 KiB / 128 KiB | 48 KiB / 96 KiB | 账户和会话品牌槽位 |
| `mark` | 32 KiB / 64 KiB | 24 KiB / 48 KiB | 侧栏和状态行；优先使用清晰的专用构图 |
| `mono` | 32 KiB / 64 KiB | 24 KiB / 48 KiB | 单色和高对比场景；不能由模糊的 `full` 缩小得到 |
| `app-icon` | 32/64/128px 各 32 KiB；256px 96 KiB；512px RGBA 192 KiB | 不作为默认 OS 图标格式 | 每个尺寸独立检查；Tauri PNG 保持 RGBA，平台容器另行转换并保留 PNG 来源 |

所有实际发布物合计目标不超过 2 MiB。超过预算时只能通过重新裁切无效留白、优化编码或调整未使用的派生物解决，不能降低可辨识性或删除必要安全区。

## 留白、焦点与清晰度

1. 在登记后的母版副本上计算透明像素边界；裁切只移除无效透明留白，主体四周保留 manifest 要求的安全区。
2. 为每个变体记录归一化焦点坐标和裁切矩形；同一变体的 1x 与 2x 必须使用相同焦点和比例。
3. 透明边缘使用 sRGB 和 alpha 预览检查，不能出现白边、黑边、锯齿或主题背景污染。
4. PNG 使用无损编码；WebP 只用于允许有损的展示尺寸，导出后必须在 1x、2x 和最小显示尺寸对比母版。
5. 最小显示尺寸下，耳朵、脸部和主体轮廓必须可辨识；`mono` 和 `app-icon` 必须使用独立简化构图，不能直接缩小 `full`。
6. 浅色、深色和透明背景预览都要检查主体对比度；出现明显色偏或细节损失时，导出失败并回到临时目录重新处理。

## 导出流程

1. RC-122 登记仓库母版路径和 SHA-256；许可证和允许复制范围由独立发布门禁管理。
2. 使用仓库内无损母版并再次校验 SHA-256；运行时不从桌面路径读取。
3. 依据 `docs/design/rabbit-asset-manifest.json` 生成裁切矩形、焦点、主题和 1x/2x 输出；原始母版保持不变。
4. 在临时目录分别导出 PNG、允许的 WebP 和应用图标 PNG，写入尺寸、哈希、色彩空间、导出工具版本和时间。
5. 执行文件预算、尺寸、透明边缘、焦点、色偏、最小尺寸清晰度和 1x/2x 对比检查；任一项失败不得发布。
6. 将通过检查的文件复制到 `frontend/public/`，运行包体/Lighthouse 检查，并确认构建输出不会写回母版。
