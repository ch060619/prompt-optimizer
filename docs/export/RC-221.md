# RC-221 Portable Format

The portable contract is `rc221-v1`. JSON is the canonical representation;
the ZIP form contains exactly two root files:

- `manifest.json`: schema version, format, data path, byte count, and SHA-256.
- `data.json`: the canonical portable document.

`data.json` contains `workspace`, `sessions` with nested `messages`, `prompts`,
`templates`, and allowlisted non-sensitive `settings`. Provider credentials,
keychain references, authorization headers, passwords, tokens, and arbitrary
unknown settings are excluded. Prompt and message text remains user-owned
content and is preserved as data rather than interpreted as a path or command.

The importer validates UTF-8 JSON, Pydantic schema fields, duplicate entity
IDs, sensitive field names, archive member names, symlinks, duplicate ZIP
entries, manifest hashes, and size limits before returning a document. ZIP
members must be root-level `manifest.json` or `data.json`; `..`, absolute
paths, backslashes, and nested paths are rejected. Import preview reports
entity counts and conflicts before the caller chooses `skip` or `replace`.

The shared implementation is
`backend/src/prompt_optimizer/export/portable.py`. It returns a validated
document for the caller to apply, so preview and conflict selection happen
before any database mutation.
