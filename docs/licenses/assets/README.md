# Asset Licenses

This directory contains license references for non-code assets used in
Rabbit Code (artwork, icons, fonts, etc.).

## Rabbit Artwork

- **License:** Documented in `scripts/check_rabbit_art_license.py` (RC-035)
- **Status:** License gate verified; artwork is original or properly licensed

## Application Icons

- **Windows icon** (`apps/desktop/src-tauri/icons/icon.ico`): Project asset
- **Linux icon** (`apps/desktop/src-tauri/icons/icon.png`): Project asset

## Notes

- Asset license checks are enforced by `scripts/check_rabbit_art_license.py`.
- All assets must pass the license gate before release.
