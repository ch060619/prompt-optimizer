# 本地模型与运行器许可证政策

RC IDs: RC-031

## 当前决定

- Ollama 和 llama.cpp 只作为待审查的运行器 Adapter 来源；固定 SHA 和 MIT LICENSE 页面已登记，具体依赖/二进制分发仍需 NOTICE 与第三方组件审计。
- Gemma 3 1B IT 使用 Gemma 专用许可标识，HF 模型卡为 manual gated；在用户确认适用条款前不得下载、打包或分发。
- Qwen2.5-Coder 1.5B Instruct 的模型元数据标为 Apache-2.0；只允许按需下载，在 UI 显示许可证和来源后由用户确认；不直接打进安装包。
- 两个模型的权重均未下载；manifest 保存的是固定提交和 HF API 提供的文件哈希/大小元数据。

## 文件级控制

- 安装前必须显示 model ID、固定来源、模型许可证、条款链接、磁盘估算和数据发送边界。
- 下载器必须在完成下载后重新计算 SHA-256，并与 manifest 的文件级哈希比较；不匹配时禁止加载。
- 未知许可证、缺少条款确认、缺少文件哈希或 gated 状态未处理的条目只能停留在 `blocked`，不能发布。
- 安装包默认不包含模型权重；离线导入也必须先校验文件哈希和用户确认。
- Runner 的 MIT 代码、第三方组件和模型权重分别登记，不把运行器许可证扩展到模型。

## 待确认

- Gemma 模型卡/固定提交页面的正文访问需要 gated 权限；本轮只保留公开 API 元数据和官方 terms URL 状态，不推断完整条款。
- Ollama/llama.cpp 的完整第三方组件清单与二进制分发 NOTICE 留给 RC-032 及后续发布审计。
