# 专有内容禁止与来源审计政策

RC IDs: RC-024

本政策适用于 Rabbit Code 的代码、测试、Prompt、文案、协议常量、资源、构建输入、依赖、安装包和发布制品。它不是法律意见；来源不明时默认禁止复用。

## 禁止项

- Claude Code/Codex 桌面专有源码、核心二进制、品牌资产、图标、截图和模型权重。
- System Prompt、内部文案、内部测试、golden fixture、私有协议常量、未公开服务端点和功能开关名称。
- source-map 还原的 `sourcesContent`、机械改写、逐字复制或仅替换变量名的衍生实现。
- 没有固定来源、许可证、版权声明、NOTICE 要求和修改说明的第三方代码、测试和资源。
- 把公开可见性、README 自述、license badge 或行为观察误写成源码授权。

## 允许输入

- Rabbit Code 自己编写的代码、测试、文案、资源和行为夹具。
- 许可证清晰且完成逐文件来源/版权/NOTICE/修改声明审查的第三方代码。
- 官方公开文档中经过引用和中立改写的事实；不复制原文长段、内部提示词或专有资产。
- 合法可执行程序的自建黑盒观察，只保存输入、输出摘要、版本、日期和中立断言。

## 每个相关 PR 的 Provenance

必须填写 `.github/pull_request_template.md` 和 `docs/templates/provenance-template.md` 中的来源、许可证、原创性、字符串扫描、相似性人工复核和审查人字段。无外部来源也必须明确写出 `None`。

## 审计流程

1. 运行 RC-023 source-map denylist 和产品输入扫描。
2. 对提交运行禁止字符串扫描，检查 source-map、内部常量、私有端点和未批准资产标识。
3. 对外部来源逐项核对固定 URL/SHA、许可证、版权、NOTICE 和修改声明。
4. 由审查人对 diff 做人工相似性和机械改写检查；自动字符串命中为阻断信号，但零命中不等于法律清除。
5. 发布前重新扫描构建上下文、SBOM、Docker 层和最终制品，并保存报告。

## 当前审计结论

- RC-024 本轮只新增政策、模板、校验器和证据，没有新增外部实现代码或专有资产。
- 当前产品输入的禁止字符串扫描通过；RC-023 denylist 扫描通过。
- 相似性审查按当前 diff 做人工记录；本政策不宣称存在通用自动相似度证明。
