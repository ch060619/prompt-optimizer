# Rabbit Code Roadmap

The execution plan in `docs/rabbit-code-310-detailed-execution.md` and the [RC traceability index](docs/traceability/rc-index.md) are the source of truth. This roadmap groups work without claiming that an item is released.

## Current work

- Documentation, developer experience, extension examples, and collaboration templates: RC-262 to RC-271.
- Windows 11 x64 and Ubuntu 24.04 x64 build/install evidence: RC-272 to RC-280.
- Final acceptance, compatibility, and release review: RC-299 to RC-310.

## Release channels

Nightly, beta, and stable are proposed channels. A channel can advance only after its documented tests, migration checks, source/asset/license records, and supported-platform evidence pass. Code signing is not a prerequisite for the current unsigned release scope.

## Proposals

New work belongs in a GitHub Issue or Discussion with an RC ID, measurable outcome, scope, test plan, and source/provenance statement. The roadmap is not a promise of dates or unsupported platforms.
