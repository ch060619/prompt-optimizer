# Contributor Covenant Code of Conduct

Rabbit Code is committed to a welcoming, safe, and technically rigorous community. Participants must be respectful, avoid harassment and discrimination, and accept good-faith technical review.

Maintainers may remove comments, close discussions, or restrict participation when behavior violates this standard. Report conduct concerns privately to the repository maintainers through the contact method in the repository profile; do not include security vulnerabilities in a conduct report.
